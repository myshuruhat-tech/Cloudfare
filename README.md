# 5AL — Android / Android TV (يشتغل أوفلاين)

التطبيق يفتح موقعك على Cloudflare (live-screen.myshuruhat.workers.dev) لما فيه إنترنت، ولما ما فيه
يقدّم النسخة المضمّنة داخل الـ APK (app/src/main/assets/web) بنفس الـ origin، فتظهر التنزيلات
والسجل والحسابات (IndexedDB / localStorage) كما هي.

## البناء
1. Android Studio -> Open -> هذا المجلد -> انتظر Gradle Sync.
2. Build -> Build APK(s) -> app/build/outputs/apk/debug/app-debug.apk

## تحديث النسخة المضمّنة
تلقائي: كل مرة يفتح التطبيق بإنترنت يحفظ آخر index.html و app.html والخط من الموقع لاستخدامه أوفلاين.
ما تحتاج تعيد بناء الـ APK مع كل نشر. (النسخة داخل الـ APK = v141، احتياط فقط.)

## مهم
- افتح التطبيق مرة واحدة بالإنترنت قبل الأوفلاين (ليحفظ نسخة hls.js داخل التطبيق).
- لو الأندرويد رفض التثبيت فوق القديم (توقيع مختلف) لازم حذف القديم، وحذفه يمسح التنزيلات.

## البناء من GitHub (بدون Android Studio)
1. أنشئ مستودع **Private** جديد على GitHub.
2. ارفع كل محتويات هذا المجلد (مع مجلد .github المخفي) في الجذر.
3. تبويب Actions -> Build APK -> انتظر ~5 دقائق -> نزّل LiveScreenTV-apk من Artifacts (zip فيه app-debug.apk).
التوقيع ثابت (app/livescreen.keystore) فكل نسخة جديدة تتثبّت فوق السابقة بدون حذف.

## إشعارات بدء البث (v2.2-notify)
- خدمة خلفية (LiveWatchService) تفحص القنوات اللي تتابعها كل دقيقة عبر kick-api على Cloudflare،
  وإذا قناة بدأت بث يطلع إشعار أندرويد حقيقي (حتى لو التطبيق مقفل).
- قائمة المتابعات تُقرأ تلقائياً من التطبيق (livescreen_favorites) كل 20 ثانية وهو مفتوح.
- أول مرة: افتح التطبيق وامنح إذن الإشعارات. الخدمة تشتغل بعدها تلقائياً وتعود بعد إعادة تشغيل التلفزيون.
- إيقافها: زر "إيقاف" في إشعار الخدمة؛ تعود لما تفتح التطبيق مرة ثانية.
- لا يطلع إشعار والتطبيق مفتوح (عندك تنبيه داخل التطبيق).

## شاشة الترحيب (v2.3-welcome)
- تظهر أول مرة فقط بعد الافتتاحية (3 خطوات: ترحيب، تحكم بالريموت، الإشعارات). للتجربة افتح الموقع بـ ?welcome=1.
- طلب إذن الإشعارات صار من خطوة الإشعارات بدل ما يطلع عند فتح التطبيق (جسر LiveNative).

## الإشعارات والجرس (v2.4-notify-bell)
- شاشة الترحيب صارت بالإنجليزي (واجهة من اليسار لليمين)، بدون زر تخطي.
- إذا إشعارات التطبيق مقفلة: أي متابعة جديدة يكون جرسها "بدون" تلقائياً مع رسالة قصيرة.
- اختيار "الكل" أو "مخصّصة" والإشعارات مقفلة يفتح نافذة "فعّل الإشعارات أولاً"؛ بعد القبول يتطبق الاختيار.
- لو الأندرويد ما عرض نافذة الإذن (انرفض مرتين) يفتح إعدادات إشعارات التطبيق (جسر LiveNative.openNotificationSettings).
- الخدمة الخلفية (LiveWatchService) تقرأ مستوى الجرس لكل قناة (livescreen_bell) وتتجاهل القنوات اللي جرسها "بدون".
- "الكل" و"مخصّصة" يعاملان نفس الشي حالياً.

## تجربة نقاط Kick (v2.11.0-kick-points-test)
- زر أخضر صغير "K" يسار الشاشة تحت (في تطبيق الأندرويد فقط). يفتح لوحة اختبار.
- Login: يفتح kick.com بكامل الشاشة لتسجّل دخول بالحساب اللي تبيه (مرة وحدة)، وزر "إغلاق" فوق يمين أو زر رجوع.
- Start: يفتح قناة Kick الرسمية في نافذة مخفية (2px، شفافة، صوتها مكتوم) ويقرأ كل الأرقام اللي تظهر في الصفحة كل 5 ثواني.
- اللوحة تعرض الأرقام (مكانها + هل جنبها أيقونة) وسجل بأي رقم تغيّر ومتى. المطلوب: حدّد أي رقم هو نقاطك.
- الملفات: assets/kick/{panel,scan,mute}.js والكود في MainActivity.kt (kickWeb).
